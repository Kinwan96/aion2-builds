# Aion 2 Class Builds (EN/ES)

Fan-made build guide for all 8 Aion 2 classes (simple & advanced modes, Daevanion planner, macro, Genus Insight).

- Images are stored locally in `img/` (downloaded by the "Download images" GitHub Action from `images.txt`). If a local image is missing, the page falls back to the original source.
- Data: questlog.gg (skills, EN/ES/KO), Wikily (Daevanion layouts and node art), Korean and global community guides.
- Game art © NCSOFT. Non-commercial fan project.
